Casks

Mac apps by Tarik Kavaz, installable with Homebrew.

Install Homebrew

Skip this if brew is already installed. Paste into Terminal and follow the prompts. 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

More options at brew.sh.

Apps

Correctify

Requires macOS 27

Menu bar grammar and spelling correction in any app, using your own AI provider key. 

brew install --cask tarikkavaz/tap/correctify

Update

brew upgrade --cask correctify

Cue

Requires macOS 14 Sonoma or later

Now-playing companion for Spotify Connect, with menu bar and desktop widgets. 

brew install --cask tarikkavaz/tap/cue

Update

brew upgrade --cask cue

Episodic

Requires macOS 27

Menu bar app that fetches new episodes from your TVmaze calendar through put.io into your library. 

brew install --cask tarikkavaz/tap/episodic

Update

brew upgrade --cask episodic

Posta

Requires macOS 14 Sonoma or later

Native Gmail client for multiple Google accounts.

brew install --cask tarikkavaz/tap/posta

Update

brew upgrade --cask posta

Stabilisator

Requires macOS 14.2 or later

Gentle system-wide dialogue leveling and volume control for the Mac menu bar. 

brew install --cask tarikkavaz/tap/stabilisator

Update

brew upgrade --cask stabilisator

VirtualRemote

Requires macOS 14 Sonoma or later

Menu bar remote for the media playing on another computer on your network. 

brew install --cask tarikkavaz/tap/virtualremote

Update

brew upgrade --cask virtualremote
